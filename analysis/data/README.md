# Tahoe-100M and EmeraldBay expression states

[`tahoe-emeraldbay-expression-states.tsv`](tahoe-emeraldbay-expression-states.tsv) contains the authors' derived expression states for 50 Tahoe-100M and 52 EmeraldBay line-by-source records. Some lines occur in both atlases. This subset retains the analysis scores and confidence calls. Screen-specific identifiers and the analysis label were dropped. Column definitions and interpretation are in the [supplement](../../manuscript/supplement.pdf).

The downloadable table uses the rerun with the study’s pinned libraries. Two lower bounds on marker-negative share changed. LoVo moved from 0.008423 to 0.008420 and SW48 from 0.259381 to 0.259378. Newer libraries gave 0.008421 and 0.259388, respectively. Every state and mosaic verdict reproduced.
