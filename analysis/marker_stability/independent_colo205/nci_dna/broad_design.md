# Independent CCLE DNA stock check

The Broad/Novartis group records ATCC as supplier of its COLO 205 sample GSM888007. The deposited gene-level copy-number table gives empty values for the eight original Y marker genes. The NCI/Candiolo 450K result was known when this follow-up was chosen. Before extracting raw CEL intensities, select every eligible non-pseudoautosomal nonpolymorphic copy-number probe set on Yp and Yq with unambiguous arm coordinates on the package reference. If physical coordinates are unavailable, obtain the vendor/primary annotation. Use the median log2 probe-set intensity on each arm, centered on the autosomal median of the same probe type. Use all available probes per retained set. Use the same CCLE series' HT-29 and HCT-15 as low/high comparison lines based on their externally reported NCI amelogenin calls. These are cell-line-level reference labels and do not certify the Broad aliquots. Keep numbers of physical sites separate from the number of independent stocks. Report the direction and the two comparator arm contrasts even if they disagree. A same-sample RNA measurement, absolute DNA copy number and breakpoint localization are outside this test.
