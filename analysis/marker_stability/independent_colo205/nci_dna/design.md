# COLO 205 chromosome Y DNA intensity

Before extracting COLO 205 measurements, select the two public 450K raw intensity deposits containing this line, NCI GSE79185 and Candiolo GSE86078. Both studies drew on the NCI-60 collection. Each is a separate assay, with unknown culture relationship. Quantify total genomic DNA fluorescence, log2(1 + methylated + unmethylated intensity), using uniquely assigned non-PAR Y probes. Prefer the published general probe mask and hg38 map. Exclude the centromere. Center each array on its autosomal median. Within each study calibrate the distribution using available NCI-60 lines with named X-only or X/Y amelogenin STR calls. Exclude COLO 205 from both reference groups. Show per-sample arm medians and positions of probes, using the same mapping and arm definitions for both series. Document ambiguous aliases, unavailable controls and coverage. Treat medians and control contrasts descriptively. Neither assay includes a validated threshold for absolute Y copy number. No RNA sample is paired by aliquot.
